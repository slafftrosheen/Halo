# First-run Halo setup

Halo opens a guided setup the first time. Choose English, Russian or Latvian, then choose what you want to try. This does not hide other features.

Continue through the steps at your own pace. Microphone and notification access are optional; type and use notes without them. Devices are optional too. If Android no longer shows a permission prompt, use Open Android permissions. Save and leave keeps your place; Guided setup in Settings lets you return.

For online answers, choose a service, open its key page, create your own key and paste it into the masked field. Save and check key validates access; then choose an answer model. Check the service's prices and privacy policy. Local/private setup instead offers explicit model download, selection and testing. Configure later keeps limited use available without an account.

For speech, select a language, download a compatible listening model if needed, then test a short phrase. Read the recognized words. Play a Halo response and confirm only if you heard it. If a check fails, retry or choose another model/voice. Downloads and tests start only when you ask.

Readiness shows which checks worked. The final step sends an actual request through Halo. Try asking the time, opening a Halo screen or creating a note. Pending approval continues in Activity. A failed or unconfirmed action is not successful setup. If you cannot complete checks, explicitly enter limited mode and repair setup later.

Settings can reopen answer, voice or readiness setup without erasing other choices. Advanced contains provider internals; Developer contains runtime detail. Optional setup diagnostics stay on this phone and include only stage, outcome and error type. Share sanitized setup report exports checks without keys, speech, private notes or device names.
