# Halo 13 Android integration

The source is Halo main at `99aac2f02` plus the checkout's local fixes. Chapter 30 of the v8.0 brand book and the five batch specifications describe the target release. The prototypes, boards, films and reference Kotlin accompany the Android implementation.

| Area | Native behavior |
| --- | --- |

| Canvas and Studio | Canvas exposes five creation verbs. A stroke that would exceed a sheet’s storage limit moves to a new sheet. Saving commits the sketches, continuation edges and group in one board edit with Undo. Studio uses the supplied project preset names. ## Functionality pass

- Sources and the registered `halo_source_preview` tool now use the same website feed discovery. Preview resolves advertised HTTPS RSS and Atom links, validates the feed under the existing Power and request-budget controls, and returns the reviewed endpoint and up to three headlines.
