## Feature Acceptance Questions

If a feature cannot answer these nine questions, it doesn't get merged:
1. Why does it exist?
2. Why locally?
3. Battery cost?
4. Memory cost?
5. Privacy impact?
6. Latency target?
7. Offline capability?
8. Test coverage?
9. Accessibility & Future-proof?
