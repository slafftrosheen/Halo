# Halo Glossary

One single definition for every core concept to prevent terminology drift.

- **Goal**: The desired end state of a cognitive process.
- **Thought**: An internal generation of the reasoning engine.
- **Memory**: A persisted piece of knowledge or experience.
- **Belief**: A subjective truth held by the system with a confidence score.
- **Task**: An actionable item derived from a plan.
- **Capability**: A tool or action the system can perform.
- **Knowledge**: Factual information available to the system.
- **Observation**: Raw data perceived from the environment.
- **Plan**: A sequence of tasks designed to achieve a goal.
- **Reflection**: The process of evaluating past actions to learn.
