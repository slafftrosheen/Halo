## Implementation limits surfaced in the product

Only installed capabilities can be reviewed or executed. There is no email/reply connector, numeric price-drop comparator, account scraping, dynamic browser execution, inferred location trigger, free-time planner or marketplace. Requests requiring these remain drafts/needs-user, with an explicit setup/take-over path. Source changes and literal text monitoring are available; they do not pretend to be those missing connectors.

The current routine scheduler supports one-shot and interval-one daily/weekly work with an explicit zone; count/until/monthly variants and device-following recurrent zones require revision before enabling. Human calendar recurrence keeps its existing broader semantics. A manual reviewed run is explicit and may precede a future scheduled start; automatic runs cannot. A saved disabled manual-only plan has no confirmed active schedule.

Research coverage is attributed and bounded. Wikipedia is reference search; Internet Archive supplies archived documents, without a promise of current coverage. Public-page retrieval accepts readable public HTTPS pages only, checks robots first, refuses page redirects and noindex/noarchive restrictions, fails closed on unavailable policy, and does not execute scripts or follow discovered links. Sites requesting any positive crawl delay are unavailable through this bounded adapter. Robots and page each reserve an outgoing request unit; unused units are conservatively retained. Local mode uses retained evidence only; no paid subscription, key or Google dependency is required.

Source visibility is rechecked for results, including derived brief dependencies. A backup keeps facts and links but clears execution binding, marks Halo work for review, pauses stopwatches, disables external refresh and revokes child grants. Reconciliation also disables old orphan routines. An interrupted claimed effect is never automatically replayed to obtain a success receipt. Its non-authorizing recovery record preserves the exact prior execution link through Stop, Take over, edits and restore; uncertainty needs explicit review before more work. Pending shared handoffs survive subsequent scheduled ticks without repeating capabilities or replacing the successful result.
