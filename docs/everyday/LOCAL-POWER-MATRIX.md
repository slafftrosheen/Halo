# Local / Power ownership and verification matrix

Audit date: 2 November 2026. This is a matrix of actual production owners, not a test that loops over UI labels. Final matching run results are recorded in the implementation ledger. UI/hardware end-to-end network observation remains a separate acceptance step.

A voice transcript does not itself execute a tool. |

New news/weather readers render sanitized text, no remote images/fonts/scripts. |

`PrivacyModeStore` increments a durable revision on mode/profile/family-authority change and cancels active leases. Queued work retains its admission revision, so Local → Power does not revive a previously authorized request. The SDK guards request admission before DNS, intercepts dispatch, cancels the actual Call, and rechecks body streaming. Collector publication also compares source version and reservation token; widget publication compares family/mode/config/source authority immediately before output. These mechanisms are tested at their actual owners; rows sharing an owner do not represent independently observed UI sessions.

The transport inventory is `docs/testing/artifacts/HALO-EVERYDAY-63-2026-11-02/transport-inventory.txt`. Raw provider default-client factories are library construction points; the shipping Android factory injects guarded clients for every remote provider, including custom OpenAI-compatible and Ollama. Public collectors require their own policy and do not inherit arbitrary provider cookies/proxy settings. Coil references in HaloFx/HaloPackageFx consume bundled themed SVG bytes. Paired-device transport must stay bounded to its device authority and cannot be a general public-URL escape; BuddyBot now enforces literal local-IP admission before DNS/socket creation, blocks redirects/proxies and fences the replaced session. BuddyBotLocalEndpointTest checks the actual client, including zero DNS/socket activity for rejected addresses and a loopback redirect fixture.

Network fixture evidence is hermetic. It establishes denied dispatch, scoped admission, cancellation and stale-work rejection for the checked owners. It does not claim a packet capture of every Home/Kids/Study session, successful third-party credentials, live feed uptime or phone background delivery. Those are hardware/provider/human acceptance, not missing implementation placeholders.
