# BrainTool Documentation

Welcome to the official documentation for **BrainTool** (Project Halo).

## Mission
Create the most capable open-source wearable AI platform that:
- never requires an account
- never requires our cloud
- never stores user data
- never locks users into one AI provider
- works offline whenever possible
- lets users choose every component
- treats glasses as an extension of the phone rather than a separate device
