# Halo execution roadmap

Status: PLANNED. Updated 2026-09-18.

[Halo Presence + Capable Assistant](NEXT-PHASE-2027.md) contains proposed batches and
acceptance criteria. [Current state](../../CURRENT-STATE.md) and
[audit](../engineering/DOCUMENTATION-AUDIT.md) describe the reviewed source.

1. Establish an honest source baseline and resolve code contradictions.
2. Develop Orb v2 and Home/task presentation.
3. Apply the shared interface to all pages.
4. Bridge tools to capabilities with authorization/cancellation/truthful receipts.
5. Align providers, Android assistant entry and audio lifecycle.
6. Complete durable memory, reminders, notifications and routines.
7. Validate wearable behavior, performance and release readiness.

The earlier PR-numbered protocol sequence is superseded as a scheduling/status ledger.
Preserve its evidence principle: retain captures, separate interpretation from observation,
test against fixtures and independently accept real hardware. Start from the existing driver,
not an assumption that decoders/captures do not exist. No batch is marked complete here.
