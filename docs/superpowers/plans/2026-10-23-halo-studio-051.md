## Design and ownership

Independent Studio destination and durable ARTIFACT Workspace object, with typed project state in the existing Room database. It is not a Canvas node or a second asset store. Immutable managed image sources and output files stay under WorkspaceFileRepository/NotebookAssetRepository ownership; project references retain exact object/version provenance. Extend CanvasImageRecipe/CanvasImageTools for bounded local composition rather than duplicate crop/rotation/export pipelines. Portable Halo Ink owns strokes, erasure and selection; Android owns pixels/capture/permissions. Studio shows its supported local operations and advanced limits plainly. Existing WorkspaceImageStudio remains the cloud proposal/disclosure/spend owner; accepted AI drafts enter the same project command path, never silently overwrite an original.
