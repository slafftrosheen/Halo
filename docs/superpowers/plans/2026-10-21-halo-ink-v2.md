# Halo Ink v2 implementation plan

**Goal:** Replace duplicated finger-drag editing with bounded, vendor-neutral pen input in Canvas sketches and PDF/image annotation, preserving old drawings.
**Authority:** Issue #28; user directed implementation and commit to main without builds/tests/CI. Hardware acceptance remains open.
**Architecture:** Portable Ink model/codec/edit history in runtime SDK; Android MotionEvent adapter in host-android; shared Compose surface in app. No new provider, driver, permission or network dependency.

- [x] Add source regression cases for v1/v2, hostile input, quota boundaries, whole-stroke erasure, cancellation and undo/redo.
- [x] Implement bounded codec and transactional history. Cancelled contact never becomes a durable stroke. Preserve v1 encoding on unchanged edits.
- [x] Implement pointer-ID ownership, batched samples, pressure/tilt/orientation, stylus priority and platform cancellation; no globally disabled touch.
- [x] Wire one input/rendering surface into both sketch and source dialogs. Add explicit draw/erase/pan modes, zoom controls, keyboard undo/redo, existing durable draft callbacks and invalid-data protection.
- [x] Add EN/RU/LV resources and adapter/integration test source.
- [x] Inspect source/resource parity and prepare an atomic commit against checked main without force. Publication is recorded on #28. No test/build results claimed.

Review focus: lossless old drawings; malformed recovery cannot overwrite an original; palm cancellation rolls back the gesture; eraser cannot mutate earlier history; page switches/dismissal abandon unfinished contact; rendering and hit testing share transforms; content limits include aggregate file/draft sizes.
