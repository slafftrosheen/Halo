## Typed operation contract

An exact TRASHED NOTE is required. A saved draft needs explicit inclusion and exact recovery identity. Attached and unattached asset metadata contributes to source identity. Restoring an ID requires a fresh source and observed prior receipt before a new deletion generation. A cached duplicate returns the old receipt without effects; missing receipt means NOT_FOUND. Retry checks current receipt identity and refuses a restored source, changed asset metadata or unsafe ownership. Cancellation protects the bounded commit/outcome handoff; postcommit file failures remain durable. A rollback after physical cleanup leaves the original note already deleted and a retry can observe absence. Receipts survive Room recreation; OS process-death acceptance remains separate.

Destructive operations retain ALWAYS approval and NEVER_REPLAY metadata; unattended always-allow cannot grant them. Existing runtime permission, Private/Power, Kids and Workspace content provenance apply. No external provider permission is opened, changed or inferred. Native tests explicitly grant synthetic calls and do not represent human approval or CognitiveSession input acceptance.
