## Typed operation contract

Metadata reads do not initialize legacy document blocks. Ordinary NOTE identity includes saved header/lifecycle/Inbox, canonical blocks or legacy body, all owned assets, live links and current draft. Specialized halo-* documents stay with their owner. Later query pages must carry the first page's attachment-set version. This identity is distinct from halo_note_get's note-content version.

Reuse checks exact target/source identities in the same Room transaction as the editor's existing-image admission. Target must be ACTIVE and have no pending recovery draft; source may be ACTIVE/ARCHIVED. Only a currently persisted IMAGE in APP_OWNED/MANAGED_FILE storage is admitted, with managed file existence rechecked. SupportsImageReuse indicates supported kind, not decoded availability or image quality. Duplicate admission returns the actual target link, unchanged. Unlink checks exact state and one selected live link, permits non-trashed ordinary notes, preserves all bytes/ownership and never reports file cleanup. Missing/stale IDs and uncertain replay are refused, not assumed success. Both writes use NEVER_REPLAY; unlink retains mandatory destructive ALWAYS approval, while ordinary reuse honors existing reversible policy. Query uses SAFE replay. Existing Kids, Private/Power, capability and Android permission owners remain in place. UI removal retains its existing active-editor draft behavior; assistant writes refuse pending target recovery.

Human picker grants and selecting new external files remain Android/user actions. This batch exposes reuse of known saved images and exact link removal, not arbitrary imports or pen gestures. Existing note/attachment UI labels are reused; no new copy or render claim.
