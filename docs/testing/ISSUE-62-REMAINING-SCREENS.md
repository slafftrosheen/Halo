## External identifier boundary

Notification Android keys can contain arbitrary tag text and pipes. They remain only in the local lease source identity, never the exported canonical object ID. Notification callbacks retain the exact original key and fingerprint admission.

Glasses object IDs are exported only when they are actual MAC-form addresses; BuddyBot IDs must match the actual host ID and identifier grammar. MCP server IDs are exported only in the UUID form generated by McpIntegrationManager. Unrecognized legacy/imported IDs stay in the local lease, with original callbacks unchanged, rather than being fabricated or normalized into a different canonical ID. User-provided device/server/chat titles render locally with titleIsSource and are not added to exported CurrentScreenMetadata.
