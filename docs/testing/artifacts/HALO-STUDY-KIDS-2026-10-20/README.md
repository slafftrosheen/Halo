# Study and Kids host previews

Eight native-renderer component compositions at 360dp, 412dp and 200% text. They use clean sample data and production UI components. These are host previews, not complete device screen captures: Android system chrome, app navigation and surrounding runtime state are not represented. Large-text content scrolls; the Kids dock remains anchored.

The raw eight PNGs are unchanged exports. preview.png and contact-sheet.png are viewing aids. Final debug assembly and 41 selected checks passed (including eight render checks), with no failures, errors or skips. Hashes, dimensions, APK identity and the local build log are in manifest.json.

Phone testing, real tutor/provider journeys and full pixel acceptance remain pending. These files were not copied into HaloWeb's real Android screenshot assets.
