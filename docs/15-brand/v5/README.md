The imported pack includes illustration sources, motion studies, and example code. Its Compose and Android samples are design references. The application runs the versioned owners under app/src/main, with the existing runtime, storage, permission and confirmation boundaries.

Live departure data is off by request. Kids identification starts off, then offers on-device labels or an approved provider configured by a grown-up. The online option requires the existing Power, image and paid-media permissions and an additional per-photo review.

Family space keeps reviewed file sharing and import. The owner chose this option for the current release.
