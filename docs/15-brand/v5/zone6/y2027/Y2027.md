# halo 2027 · quietly ahead (pack 7.4, boards 47–51)

Nothing here changes the Zone 6 rules: bottom 25% = halo zone, top 75% = work, ring labelled, one filled primary per dock.
Colour meanings unchanged: mint = listening/working/done · Apricot = needs you · lilac = help · red = error.

## 47 · Hand it to halo — `HaloTaskPlan.kt`
- Multi-step asks become a **plan card**: numbered steps, "reads / web / asks you first" tags, the apps it will touch.
- **Hard stops** (data: `HardStop`): money, messages to people, deleting, posting. Always ASK_FIRST, on every device, at every helpfulness level.
- Working → island "Finding a table · Step 2 of 4" + Stop. Needs you → Apricot island, button names the action ("Book it").
- Done → **receipt**: each line has its own undo (Cancel / Remove / See / Change). Saved in Activity › Done.

## 48 · Outside the app — `HaloLiveUpdate.kt`
- One ongoing notification per running plan. Android 16+: promoted ongoing, status-bar chip ("2/4", "Needs you"), ProgressStyle segments = plan steps, Apricot points on ASK_FIRST steps.
- Lock screen = public version: title + step only.
- "While you were away" digest groups needs-you first.
- **Circle to ask**: hold the home bar or the ring, circle → assistant island with actions for that thing + "Screen used once, not kept".
- Home-screen widget shows the same task (Glance/RemoteViews from widgets-build).

## 49 · Next for you — `HaloNextForYou.kt`
- Max 1 card visible, max 3 per day, never during quiet times (sleeping, driving, meeting), dismissed kind won't return the same day.
- Every suggestion has reasons; "Why this?" (lilac) lists source + on-phone, learned habits can be forgotten in place.
- Levels: Only when I ask · **Suggest, I decide (default)** · Quiet helper (small safe undoable actions, told after; never hard stops).
- After 21:00 Home shows "Today, done".

## 50 · Trust you can see — `HaloTrust.kt`
- Every answer has one origin chip: mint "On this phone" · blue "Used online · weather" · dashed "Private · nothing kept". Tap → one lilac sentence of what was sent.
- Privacy at a glance: weekly numbers (on phone / online / shared) + permissions with "last used".
- Pause halo: 30 min / 1 hour / until tomorrow; ring grey, caption "Paused", widgets "Paused"; alarms still ring.
- Private chat: dashed dock edge, grey ring, caption "Private".

## 51 · Across your things — `HaloFollowMe.kt`
- Follow me: next question goes to the device in use; phone island says where it went.
- Approve on watch: small OKs only. Money and deletes always route to the phone.
- Devices list uses the 7.0 states: Ready · In use · Asleep · Needs a look.

## Acceptance (to test on a phone — not done)
1. A plan never runs a hard-stop step without an explicit tap.
2. Lock screen never shows message text, names or amounts.
3. Only one halo status-bar chip at any time.
4. Next for you never shows 2 cards; never shows while driving.
5. Every answer bubble has exactly one origin chip; TalkBack reads it.
6. Paused: no microphone use, no learning, no background plan steps.
