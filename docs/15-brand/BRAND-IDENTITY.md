# HALO Brand Identity Prompt

## Project Overview
Halo is not another AI chatbot.
Halo is an AI-first Cognitive Operating System (COS) designed to function as a persistent, modular intelligence layer across devices.

Unlike traditional assistants that simply respond to prompts, Halo continuously perceives, interprets, reasons, plans, remembers, learns, and executes actions through a structured cognitive architecture.
Internally it consists of independent cognitive engines connected by a shared Blackboard, memory system, executive controller, planning engine, reasoning engine and modular capabilities.

The user should feel as though they are interacting with an intelligent operating system rather than a chatbot.
The visual identity must communicate calm intelligence, engineering quality, trustworthiness, and elegance.
Avoid anything that resembles existing AI company branding.

## Possible Symbol Directions

### Option A: Minimal orbit
A central core surrounded by one elegant incomplete orbit.
Represents: continuous cognition.

### Option B: Converging rings
Several thin rings converging into one focus.
Represents: multiple cognitive engines becoming one intelligence.

### Option C: Abstract halo
A perfectly balanced ring with one intentional asymmetry.
Represents: continuous perception.

### Option D: Layered aperture
Minimal aperture-like geometry.
Represents: focus and observation. (Not camera. Not photography.)

### Option E: Cognitive pulse
A flowing circular signal.
Looks alive without animation.

## Visual Language
- Rounded geometry.
- Balanced spacing.
- Thin strokes.
- Subtle depth.
- No glossy effects.
- No excessive gradients.
- Prefer solid colors or very soft radial lighting.

## Motion
Animations should be slow, smooth, purposeful.

- **Listening ↓** Ring gently breathing.
- **Thinking ↓** Inner orbit rotates slowly.
- **Planning ↓** Segments connect.
- **Executing ↓** Signal moves outward.
- **Speaking ↓** Very subtle pulse.

Everything should feel alive. Nothing should flash.

## Overall Feeling
When someone opens Halo for the first time, they should not think:
"This is another AI app."

They should think:
"This feels like the operating system for intelligence."

The visual identity should communicate confidence through restraint. It should feel engineered rather than decorated, premium rather than flashy, and timeless enough that it still looks appropriate five years from now. The logo should be something that could sit comfortably alongside Android, GitHub, JetBrains, Figma, or Linear—not because it imitates them, but because it shares the same discipline of simple forms, strong proportions, and purposeful design.
