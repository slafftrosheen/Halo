# Screen workspace — issue #37

The existing Chat | Screen placement and BrandBook Open Ring remain. This extends
chapter 19 with the user-approved desk-workspace direction; source and physical
qualification are separate.

Viewing uses quiet native surfaces over Plain/Mint/Warm/Cool theme backgrounds.
The clock is the focal point. Card titles, source content and freshness remain
separate. There are no permanent action rows on cards. Customize and Desk mode
are explicit; New note delegates to the existing Home/Notebook owner. The shared
#46 orb provides voice, critical Stop/review and canonical tool discovery.

Customize is a retained local preview. Apply saves atomically against its base;
Cancel/Back restores the saved view. Conflict means reopen the preview, never
overwrite a newer source change. Each card has a move handle, options and a resize
corner. Options offer the same horizontal/vertical movement and sizing, typography,
pin/archive/hide. Keyboard arrows move; Shift + arrows resize. Native accessibility
actions have card-specific labels and omit unavailable sizing directions.

The bounded canonical grid uses twelve tracks to map to 2/3/4 visible columns.
Height spans are minimum sizes; measured text expands rows. At 200% text the grid
uses one column without changing saved horizontal placement. Explicit moves still
work in that view. Named layouts preserve card references/config and appearance;
loading or restoring a starter opens a preview. Undo restores applied presentation
without deleting notes, calendar data, routines or research.

Fonts are App default, System, Sora and Atkinson. Bundled Cyrillic text uses the
existing Onest fallback when needed. Title/content emphasis is bounded at 100–150%;
clock emphasis at 100–200%, on top of OS scaling. Desk emphasis never reduces an OS
setting and does not turn 200% into 280%. Translucency is restrained and private
cards always use opaque masks.

Plain-language composition stays a bounded native proposal. Each change and any
research handoff is independently selectable. Preview on Screen is editable;
Apply/Undo remain explicit. Weather/interests retain Needs setup until actual
sources exist. The phone card reports actual battery observations, never inferred
device readiness. Real routine/research records retain stable IDs and attribution.

Desk mode is in-app. Exit remains visible; interaction reveals contextual controls,
and active voice/Stop keeps the orb visible. Sensitive cards and details are masked
by default, and always while locked, screen-off or backgrounded. Ambient snapshots
use a scoped secure-window flag. Charging keep-awake is bounded by battery, saver,
thermal and lifecycle observations. Missing observations disable keep-awake.
Brightness, bars and flags restore on exit. Small five-minute shifts mitigate
burn-in; no system AOD, overlay or always-on microphone capability is claimed.

Required native states: light360, dark412, RU/LV200, wide multi-column placement,
short landscape/200%, edit handles/options, source-ready/stale/error/setup cards,
ambient private masks, reduced motion and saved-layout preview. Actual phone resize,
Undo/restart/rotation, notes, voice, keyguard, battery/thermal and accessibility
acceptance must be recorded by observation under #37/#43, never inferred from frames.
